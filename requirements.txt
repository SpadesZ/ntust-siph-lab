#
# 版本鎖定政策（SAI 附錄 E：pinned dependencies）：
#   使用 ~= 允許修補版更新（安全修補），但鎖定次版本，
#   避免次版本的破壞性變更讓 Cloud Run 部署在無人察覺下失敗。
#
# 分組說明：
#   [Web]      Flask 與其官方擴充
#   [DB]       SQLAlchemy / Alembic / PostgreSQL driver
#   [Media]    影像處理
#   [Cloud]    GCP 相關（僅 production 需要，但一併安裝以確保
#              同一個 image 可跑 local 與 cloud —— SAI §25：
#              「同一套程式碼，環境差異只在設定」）
#   [Runtime]  WSGI server 與時區資料
#
# 維護契約：
#   升級任何套件後必須跑完整 pytest 與 flask db upgrade，
#   並確認 SQLite 與 PostgreSQL 兩種 DB 都通過
#   （tests/test_db_portability.py）。
#
# 驗證方式：
#   pip install -r requirements.txt && pytest
# ============================================================
